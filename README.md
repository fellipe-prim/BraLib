# BraLib

BraLib é uma plataforma de livraria digital onde usuários podem navegar pelo catálogo de livros, realizar compras e acessar sua biblioteca pessoal com os títulos adquiridos.

O projeto possui uma aplicação web desenvolvida em React e uma API em PHP, utilizando MySQL como banco de dados.

## Tecnologias

### Front-end
- React
- Vite
- Tailwind CSS

### Back-end
- PHP
- MySQL
